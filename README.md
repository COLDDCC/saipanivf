# Saipan IVF Center · Coastal Editorial Demo

Competition-ready visual prototype using the approved **Coastal Editorial V3** design language, with updated content for a **cross-border fertility consultation and medical coordination** brand.

## Preview

## Included

- Full-screen Saipan coastal hero identifying IVF / ICSI and the coordination model
- IVF, ICSI, third-party reproduction consultation overview
- Medical coordination process, destination positioning, cost breakdown
- Journey steps, FAQ, supporting image galleries
- Responsive layout with collapsible mobile navigation
- Accessible consultation demo form with *client-side-only* feedback

## Important Demo Boundaries

This is a **concept demonstration**, not a verified operating clinic website. It does not represent actual partners, doctors, medical outcomes, fees, visa rights, legal permissions, or guarantees. The consultation form does **not** send or store submissions.

Referenced photography is currently loaded from a separate publicly accessible project (`jiusongvip/saipan`) and should be replaced or hosted locally before independent production deployment. This site has no backend or real medical intake process.

## Source Design

Adapted from the user-provided `saipan-coastal-editorial-v3-full(2).html` visual reference. Preserves its editorial typography, mist blue / deep ocean palette, generous whitespace, Saipan photography, and section pacing.
