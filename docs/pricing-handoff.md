# 服务与定价交接

首页预算由 `src/data/pricing.ts` 统一维护，组件为 `src/components/TreatmentPricing.astro`。所有金额均为未确认的方案假设，不是SIVF报价。

正式定价前由医疗与财务共同确认：
- 接诊主体、项目实际交付地点和可预约范围。
- 每一项目价格、币种、有效期、计费单位及成本。
- 取卵基础费是否含麻醉、ICSI、监测；移植费是否含药物；冷冻是否含首年保存。
- 初诊和基础评估是否重叠收费；PGT的活检、枚数、运输和检测如何收费。
- 取消、无卵可取、未形成胚胎、未移植及追加周期如何结算。
- 供应方独立收费、付款节点、退款及旅行取消条款。

计算器仅做费用组合，不推荐治疗，不将ICSI或PGT视为必需。冻卵和仅移植路径会隐藏不适用项目；IVF初始示例为$26,100–31,100，勾选PGT后为$29,100–37,100。

官网团队介绍仍属官网公开资料整理，当前排班与资格需向院方复核。咨询清单只在本地生成，不提交病历。
