## 十篇实验后的 Skill 沉淀要求
1. 至少抽样 3 类搜索意图：费用、流程、入境/旅行，避免仅凭费用文章总结。
2. 记录文章首屏答案、内容来源、图表/交互、简繁语言差异、内链和页面指标。
3. 测量构建和移动端无障碍问题；如果有 Search Console 数据，再对比曝光、点击与搜索查询，避免把排名变化归因于某一个页面设计细节。
4. 只有在多篇复用的规则才能进入下一代 Skill。确实需要按文章类型区别处理的内容保留为变体。

## 第 1 篇阅读层改版（2026-10-26，taste skill house rules）
- 问题：全局 site.css、组件内两套 body 底色互相覆盖；答案卡、提示框、表头、合计行、引用角标都是浅蓝色块，长段中文阅读时底色频繁切换；段落一行约 47 个汉字。
- 改动：`html body.article` 作用域的全局样式，压过 site.css/typography.css；整页纯白 + 唯一中性面色 `#f5f6f6`（只用于答案卡、提示框、FAQ）；正文 `#2a3238`（13:1）、次要文字 `#5b666e`（5.9:1）、强调色 `#0f5f8c`（6.9:1）只用于链接和按钮；正文 17px / 1.85，限宽 38em；表格保留线但去掉底色，数字列统一右对齐；目录改纯文字；删除 eyebrow 与大写 kicker；正文链接恢复下划线。
- 只采用 taste skill 的 house rules、colour.md、type.md；未使用落地页的抽方向、配图和滚动场景流程（不适合费用长文）。
- 验证：本地无法安装 npm 依赖（registry 被网络策略拦截），完整构建交由 CI；用相同 CSS 渲染页面片段在 1440 / 390 宽度截图自检，无横向溢出。
- 可复用：若线上效果确认，下一步把这套样式抽成 `src/styles/article.css` 给 ivf-cost 等文章共用。
