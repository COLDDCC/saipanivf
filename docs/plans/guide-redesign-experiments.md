## 第 1 篇：塞班冻卵费用 2026
- 页面：`/guides/egg-freezing-cost/`、`/zh-hant/guides/egg-freezing-cost/`
- 日期：2026-10-26
- 对标：ProIVF 的地区 IVF 决策指南，参考其先回答费用、再列细目、再提供可执行决策建议的组织方式（具体 Miami URL 当前抓取受限，不宣称完整设计审计）。
- 改动：增加文章锚点导航、用户就诊三阶段、跨机构报价比较表，保留已有预算区间、真实引用与 FAQ。
- 避坑：预算数字绝不冒充诊所真实报价；不写确定的停留天数、冻卵成功保证；不要为多语言文章各造一套 HTML 设计系统。
- 技术发现：`src/integrations/traditional.mjs` 的构建钩子会覆盖明确编写的繁体页面；已针对两篇专门翻译的费用指南排除自动覆盖。
- 未完成验证：线上预览、移动端截图、CI、`npm run verify` 需要实际运行后补充。
- 下一篇待验证：`ivf-cost` 是否可以复用文章目录、流程、比较表而不产生重复 SEO 内容。

## 十篇实验后的 Skill 沉淀要求
1. 至少抽样 3 类搜索意图：费用、流程、入境/旅行，避免仅凭费用文章总结。
2. 记录文章首屏答案、内容来源、图表/交互、简繁语言差异、内链和页面指标。
3. 测量构建和移动端无障碍问题；如果有 Search Console 数据，再对比曝光、点击与搜索查询，避免把排名变化归因于某一个页面设计细节。
4. 只有在多篇复用的规则才能进入下一代 Skill。确实需要按文章类型区别处理的内容保留为变体。
